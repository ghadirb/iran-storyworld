# روایت ایران (Iran Storyworld)

مجموعهٔ داستانی کوتاه و سینمایی (هر قسمت حدود ۶۰ ثانیه) دربارهٔ تاریخ و تمدن ایران برای کودکان ۷ تا ۱۰ سال.
فصل اول: **پارسه (هخامنشی)** با شخصیت‌های تخیلی «تیرداد» و «هنو».

- شروع کار برای هر انسان یا مدل: [`HANDOFF.md`](HANDOFF.md)
- منبع حقیقت مجموعه: [`docs/00_series_bible.md`](docs/00_series_bible.md)
- منابع و برچسب اعتبار ادعاهای تاریخی: [`docs/04_sources.md`](docs/04_sources.md)
- ساختار قسمت‌ها: [`episodes/`](episodes/) و قالب‌ها در [`templates/`](templates/)

اصل اصلی: واقعیت تاریخی، احتمال/اختلاف، بازسازی هنری و تخیل همیشه از هم جدا و برچسب‌دار می‌مانند.
