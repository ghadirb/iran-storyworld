# آزمایش انیمیشن سه‌بعدی فصل ۳

این فایل یک نمونهٔ فنی سبک با Three.js برای آزمایش روش ساخت صحنه در مرورگر است.

## اجرا
- فایل `ch03_ep01_preview.html` را در Chrome یا Edge باز کنید. اتصال اینترنت لازم است تا Three.js از CDN بارگذاری شود.
- «پخش» و نوار زمان را برای بررسی صحنه به‌کار ببرید.
- «ضبط WebM» کلیپ ۱۲ ثانیه‌ای را از canvas مرورگر ضبط می‌کند. پس از پایان ضبط، لینک دریافت ویدئو ظاهر می‌شود.
- این نمونه صدا ندارد؛ هدف فعلاً آزمودن مدل‌سازی ساده، حرکت دوربین و خروجی ویدئویی روی رایانهٔ کم‌توان است.

## محدودیت‌ها
- شخصیت‌ها مدل‌های ساده و موقت‌اند و با مرجع تصویری نهایی تیرداد و هنو تطبیق کامل ندارند.
- خروجی ضبط مرورگر WebM است، نه MP4. در صورت نیاز می‌توان آن را با FFmpeg به MP4 تبدیل کرد.
- برای نسخهٔ نهایی، از تصاویر مرجع موجود در پروژه برای تطبیق چهره‌ها، لباس‌ها و سنگ استفاده شود.
- این نمونه در این مرحله یک آزمایش فنی است؛ به‌معنای تأیید تاریخی یا تأیید کانن نیست.
