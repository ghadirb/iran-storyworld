# پیش‌نمایش تصویری «سنگی که برگشت»

این نمونهٔ سبک از تصاویر مرجع ذخیره‌شده در `assets/images/` استفاده می‌کند و به‌جای شخصیت‌های هندسی، حرکت دوربین و زوم نرم را روی تصویرهای واقعی اجرا می‌کند. هیچ کتابخانهٔ سه‌بعدی یا CDN لازم نیست.

## اجرای آفلاین
1. از مخزن، ZIP کامل بگیرید: https://github.com/ghadirb/iran-storyworld/archive/refs/heads/draft/season-3-revisions.zip
2. ZIP را از حالت فشرده خارج کنید.
3. فایل `tools/animation-test/ch03_ep01_preview.html` را با Chrome یا Edge باز کنید.
4. پوشهٔ `assets/images/` را در همان ساختار مخزن نگه دارید؛ HTML ابتدا تصویرهای محلی را می‌خواند. اگر تصویر محلی پیدا نشود، نسخهٔ آنلاین مخزن را امتحان می‌کند.

## کنترل‌ها
- «پخش» و «مکث» برای اجرای پیش‌نمایش ۱۶ ثانیه‌ای
- نوار زمان برای رفتن به هر بخش
- «ضبط WebM» برای ضبط خروجی canvas در مرورگر و دریافت فایل ویدئویی

## تصاویر مرجع
- هنو: `assets/images/هنو.png`
- تیرداد: `assets/images/نیرداد.png` (نام فایل در مخزن همین است)
- سالار کاروان: `assets/images/سالار کاروان.png`
- نشان روی سنگ: `assets/images/نماد روی سنگ.1.png`

تصویر سالار کاروان فقط برای تداوم طراحی نمایش داده می‌شود و به‌عنوان حضور او در صحنهٔ کارگاه روایت نمی‌شود.

## محدودیت‌ها
- این نسخه یک **animatic دوبعدی مبتنی بر تصویر** است: زوم، حرکت قاب و تغییر نما دارد؛ انیمیشن مستقل صورت/دست یا مدل سه‌بعدی واقعی ندارد.
- چون تصاویر مرجع ممکن است پس‌زمینهٔ خود را داشته باشند، فعلاً به‌صورت تصویر کامل نمایش داده می‌شوند؛ برای حرکت مستقل شخصیت‌ها لازم است نسخه‌های برش‌خورده با پس‌زمینهٔ شفاف و لایه‌های جداگانه تهیه شود.
- خروجی ضبط مرورگر WebM است، نه MP4. در صورت نیاز می‌توان آن را با FFmpeg به MP4 تبدیل کرد.
- این نمونهٔ فنی است و به‌معنای تأیید تاریخی یا تأیید کانن نیست.
